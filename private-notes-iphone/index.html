Privacy by design

Protection using Apple technologies.

Sensitive values can be stored in Apple Keychain. Face ID or Touch ID can lock the app, while optional iCloud sync lets you choose whether to keep information available across devices.

This makes iKeep useful for private reference information you want nearby without leaving it exposed in an ordinary note.

Frequently asked questions

Before you start

How does iKeep protect private notes?

iKeep can store sensitive values in Apple Keychain and lock access with Face ID or Touch ID.

Can I use iKeep without iCloud sync?

Yes. iCloud sync is optional, so you decide whether information should be available across your Apple devices.

Which Apple devices does iKeep support?

iKeep supports iPhone and iPad, with access from Apple Watch plus widgets and iMessage features.
